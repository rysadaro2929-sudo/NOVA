# NOVA Social roadmap

## Foundation included
- Responsive social home/feed visual foundation
- Stories and post composer interface
- Navigation foundations for Discover, Shorts, NOVA Video, Messenger, Community, Saved, Creator Studio, NOVA AI and Settings
- Supabase starter schema with RLS

## Integrations still required
- Authentication and profile management
- Live feed queries, comments, reactions and follows
- Secure media storage and story publishing
- Realtime messaging, presence and notifications
- AI Edge Function with provider-side secrets, safety and usage limits
- Video hosting/streaming and content moderation
- Creator analytics and compliant monetization
- Search indexing, reporting and admin tools

Third-party-inspired capabilities should use official APIs and comply with each provider’s terms. Do not scrape or embed restricted content.
